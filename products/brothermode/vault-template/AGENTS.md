# Vault constitution

Rules for every session that reads or writes this vault.

1. Session start: read Home, the active project's Overview and Open-Items, and the
   Failures-Index for the area you are about to touch. Recall is a query, not a
   tour: read what the task needs, never the whole vault.
2. During work: checkpoint findings, decisions, and qualifying failures at
   milestones, not only at session end.
3. Session end: one session log in the project's Sessions folder, Overview and
   Open-Items updated, Home refreshed when its lists changed.
4. Link every new note with [[wiki-links]] to what it builds on, supersedes, or
   contradicts, so recall follows edges instead of scanning folders.
5. Hygiene mirrors active forgetting: superseded notes move to 90-Archive with a
   pointer left behind; resolved Open-Items close the same session; stale findings
   get corrected or archived when discovered. A memory that only grows becomes
   noise itself.
6. The telemetry folder is machine-written (see tools/bm_telemetry.py). Humans and
   models read it; only hooks write it.
