# bundle: what is generated here, what is authored, and which check reads each

- Generated, never hand edited (edit the source, regenerate): `bundle/runtime` from `scripts/` and the product tools by `python3 scripts/bundle_runtime.py`; the six verb skills `bundle/skills/brother-start` to `bundle/skills/brother-help` by `python3 scripts/codex_surface.py`; `bundle/codex-skills` (the frontmatter stripped mirror) by `scripts/codex_skills.py`; `bundle/hooks/hooks.json`, `bundle/cursor-hooks` and `bundle/runtime/hooks/HOOKS-MANIFEST.json` by the hooks generator inside `scripts/bundle_runtime.py`, reading `products/brothermode/hooks/hooks.json` and `products/brothersbe/hooks/hooks.json` (the authored handlers, with their class); `bundle/runtime/RUNTIME-MANIFEST.json` by the same generator.
- Authored, edited by hand on purpose: the door `bundle/skills/using-brother/SKILL.md` itself (`scripts/codex_surface.py` says so in its first lines: the door is hand written, the six verbs are generated) and the door's authored references under `bundle/skills/using-brother/references` (intake.md, native-mobile.md, cursor-native.md, router-details.md); exactly three references there are generated by `codex_surface.expected()`: retired-names.md, cursor-dispatch.md and cursor-execute.md. Also authored: `bundle/commands/brother.md`, `bundle/.claude-plugin/plugin.json` (its version moves through `scripts/version_source.py`), `bundle/MANIFEST.json`, `bundle/mcp.json`, `bundle/agents`, `bundle/rules`, and this note. The door is held readable by `python3 scripts/test_skills_portable.py`.
- Identity: the sha256 of `bundle/runtime/RUNTIME-MANIFEST.json` is what a journey record and the go/no-go bind to, so any change under `bundle/runtime` re-binds every journey record `scripts/journey/run_journey.py --record` writes (the hub keeps them under docs/plan as JOURNEY-J1.json and siblings); walk last, once, on the frozen tree.
- Nearest checks after a regeneration, in this order: `python3 scripts/bundle_runtime.py --check`, `python3 -B scripts/test_bundle_runtime.py`, `python3 scripts/codex_surface.py --check`, `python3 scripts/test_skills_portable.py`, `python3 scripts/test_codex_package.py`, `python3 scripts/kernel_closure.py --check`; after a hook shape change, the HP1 suites (`scripts/test_host_live_proof.py` and its siblings) and `scripts/test_brother_hook.py`.
- Product manifests are separate: from the product folder, `git add -A . && sh scripts/checksums.sh CHECKSUMS.sha256 && git add CHECKSUMS.sha256` (the script rewrites the file after the first add), then `python3 scripts/product_manifests.py --check` from the root.
- A hand edit of a generated file fails its `--check` and the whole gate; the fix is in the source the generator reads. A hand edit of an authored file is reviewed like any other change.
