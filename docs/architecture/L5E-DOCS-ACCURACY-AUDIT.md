# L5e documentation accuracy audit

This document records the L5e documentation accuracy audit for unit L5e.
It is assembled by scripts/system_doc.py's build_audit_doc from one
section per checked area plus a score table with one row per checked area.

## SYSTEM.md accuracy

SYSTEM.md is regenerated by scripts/system_doc.py and diffed against the
checked-in file. An empty diff means the checked-in file is current; a
non-empty diff blocks. The enforcing function is compute_system_doc_diff.

## PARITY-MATRIX accuracy

Every MIGRATED and COVERED claim in docs/architecture/PARITY-MATRIX.md is
extracted and each claim must resolve to a real path or module and to a
symbol contained there. A claim that does not resolve blocks.

## README install accuracy

Every install command in the README Installation fenced block is extracted
and run in a fresh temp directory with a temp HOME. Each command must
exit 0 before the README install steps are counted as proven.

## Score

This sub-unit parses the score table below, computes the weighted
average of the per-section scores on the 0.0 to 10.0 scale and gates the
result at 8.5 out of 10.0. A missing table, an empty table, a
non-numeric or non-finite entry, a score outside 0.0 to 10.0, a
non-positive total weight or a weighted average below 8.5 blocks with
ValueError, enforced by score_audit_doc and test_score_gate. The table
has one row per checked area plus an overall row.
