# Execution flow

1. **Intake:** inspect context and create/validate the outcome contract when needed.
2. **Plan:** bounded units with objective, check, writes, dependencies.
3. **Claim/isolate:** claim before work; separate worktree/lane.
4. **Execute:** edit declared paths only.
5. **Verify:** run deciding/assurance checks; distinguish green-but-nondiscriminating evidence from PASS.
6. **Integrate:** audit scope, then integrate verified units serially.
7. **Receipt:** durable per-unit/per-file evidence and unresolved gaps.
8. **Human decision:** acceptance/release remains explicit.
9. **Reality:** where claims depend on production/later outcomes, observe reality rather than pretending pre-release evidence proved the future.
