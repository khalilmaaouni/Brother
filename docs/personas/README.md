# Professional lenses

Professional lenses answer: **what does meaningful evidence look like for this kind of work?**

They are not product modes, separate agents the user must choose, or values promised by the current outcome-contract schema. Brother should infer and compose them from the task. A revenue pipeline can need data engineering, analyst semantics, technical BA mapping, and QA oracle discipline together.

Senior practitioners do not need longer questionnaires. Inspect first; ask only when the answer can materially change scope, risk, evidence, or execution. The best pack identifies the few invariants/failure modes deserving independent evidence, not the most tests.
