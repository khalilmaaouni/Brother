# Memory is not proof

Durable memory is useful because teams repeat failures: migration traps, misleading metric definitions, flaky tests, vendor quirks, and architectural mistakes.

The danger is turning remembered text into invisible authority.

Brother's safe model is:

**memory proposes context; current evidence decides truth; humans decide authority.**

A Vault lesson can be stale, overgeneralized, poisoned, or written under a different system state. Senior practitioners benefit from durable invariants, incident symptoms, semantics, accepted exceptions, and test oracles only when current evidence can still override memory.
