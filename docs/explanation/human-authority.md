# Human authority

Brother can automate execution and evidence gathering without automating away responsibility.

Evidence is scoped. A green suite does not prove a release is strategically right. Reconciled migration rows do not prove the maintenance window is acceptable. Architecture fitness checks do not decide whether the organization wants the resulting cost.

Brother should compress the right evidence and surface uncertainty. It should not impersonate acceptance, release, or organizational authority.

A worker can hand back verified local work without silently deciding that the default branch or production should change.
