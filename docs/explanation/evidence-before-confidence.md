# Evidence before confidence

Fluency, confidence, and passing tests are not the same as evidence for the claim a reviewer cares about.

Brother separates:

1. **Work**: what changed.
2. **Evidence**: observations supporting/contradicting a named claim.
3. **Authority**: who decides whether evidence is sufficient to accept, merge, release, or act.

Collapsing these layers creates predictable false confidence. The same agent writes code and a test asserting its own interpretation; the test passes; the summary says verified; the reviewer assumes an independent requirement was satisfied. Independence was never established.

Brother's receipt makes the chain inspectable so the reviewer can decide whether the evidence matches the risk.
