# Professional personas

Brother は persona ごとの mode を増やすのではなく、仕事に必要な professional practice を組み合わせます。

対象: Senior backend engineer, Senior data engineer, Senior infrastructure engineer/SRE, Architect, Data analyst, Data scientist, Business analyst, Technical business analyst, QA/QC automation engineer, Manual QA/QC, Solo founder.

Revenue metric の pipeline change なら Data Engineering の reconciliation、Analyst の metric definition、BA の acceptance traceability、QA の independent oracle が同時に必要になることがあります。

ユーザーに mode を選ばせず、Brother が task と risk から必要な lens を読むべきです。

English details: [Professional lenses](../personas/README.md).
