## What this release carries

Drafted by Codex exec on 2026-09-11 (release-orchestrator pass 5, log codex-notes-pass-5.out under the cut evidence; the export gate sentence by pass 6, log codex-note/codex.out under the cut owner evidence), verified against the tree by the cutting session.

Brother 1.0.13 automatically skips planning for small requests that name existing files and a recognized check and meet the safety conditions (fast_route_eligibility in scripts/brother_run.py; docs/decisions/light-path-for-small-changes-2026-09-04.json, decided block; python3 scripts/test_fast_route.py).

The small-change route keeps the same checks on undeclared file changes and the same per-file receipt fields (python3 scripts/test_fast_route.py).

Acceptance of a cited run requires a review receipt or a recorded review skip naming the reason and decision maker (scripts/accept_delivery.py; python3 scripts/test_accept_delivery.py).

Recovery tests cover a three-day gap with changed files and require a recommendation to check the work again (python3 scripts/test_continuity_days_gap.py).

Crash recovery tests kill the running controller and check that restarting neither loses nor duplicates work (python3 scripts/test_crash_resume.py).

Experimental swarm resilience unit SR-1 treats an empty answer or an account-limit answer from a model worker as a failure (scripts/model_worker.py; python3 scripts/test_model_worker.py).

Experimental swarm resilience unit SR-4 pauses new dispatch after consecutive account-limit failures (scripts/loop_bridge.py; python3 scripts/test_loop_bridge.py).

The runtime bundle check compares every shipped runtime file against its source, including mirrored files outside the hooks list (python3 scripts/bundle_runtime.py --check; python3 scripts/test_bundle_runtime.py).

The export readiness gate checks its six-item assessment rather than the consolidated battery before accepting a tag (scripts/export_public.py; python3 scripts/test_export_public.py).

The file-ownership gate refuses work naming file paths when its ownership records cannot be read (products/brothermode/tools/bm_gate.py; python3 products/brothermode/tools/test_bm_gate.py).

The release cut script stops when the release-invariant command fails (scripts/cut_v1.0.0.sh; python3 scripts/test_cut_invariant_step.py).

The README first-run transcript is generated from stored run facts (scripts/readme_receipt_sample.py; readme-honesty check in scripts/check_all.sh).

Every delivery report ends with one receipt sentence per unit, the acceptance screen line and, where a risk class was named, the release screen line, and the scoping sentence `exit 0 means no check failed. It does not mean everything is proven: only the checks named above ran, and a check nobody wrote cannot fail.` Proven by `python3 scripts/test_receipt_door.py` at 198 OK.

Each wait during a run prints one governor line when it starts and one when it ends, never once per poll. Proven by `python3 scripts/test_brother_run.py` at 253 OK.

The recall hook prints `Recalled N lesson(s) from the Vault for <file>` before an edit of a file the Vault knows. It prints nothing on a genuine no-match, and writes nothing before consent. Proven by `python3 products/brothermode/tools/test_vault_recall_hook.py` at 62 OK.

Vault promotion enforces separation of duties. `SEPARATION_OF_DUTIES_ENFORCED` is `True`, and an author cannot approve the same candidate: flipping the flag turns `test_the_default_policy_is_on_the_same_actor_is_refused` and `test_the_same_actor_with_no_enforce_argument_is_refused_by_default` red. Proven by `python3 products/brothermode/tools/test_bm_vault_lifecycle.py` at 42 OK.

The promote command and the approval pane apply the same rule, proven by `python3 products/brothermode/tools/test_bm_vault_promotions.py` at 23 OK and `python3 products/brothermode/tools/test_bm_vault_pane.py` at 12 OK.
