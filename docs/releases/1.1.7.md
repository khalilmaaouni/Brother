## What this release carries

A builder or loop seat now reports DONE through one proof only: the boxed done check run by `close_unit`. A skipped test reads PARTIAL, never DONE, and before DONE a preflight runs five integration lints over the lane. Proven by `python3 -B scripts/test_builder_preflight.py` at 21 OK on both supported Pythons.

The deployed loop now judges its own next generation: generation N judges generation N+1. A landing that changes a loop tool deploys only after a boxed whole gate and a canary pass. A judge file that changes stays pending until the owner approves it with a code, and while it is pending the judge lays the previous generation's root, its runtime mirror and its manifest entry as one set, so the three never disagree. Proven by `python3 -B scripts/test_land_batch_loop_guard.py` at 52 OK.

The loop landed a real change by itself, end to end. On 2026-10-21 unit PP1.c went through the live deploy step, the judge's boxed whole gate read 63 rows with 0 failed and 0 no data, and the change landed.
Every loop launch now arms a watcher. It announces a stuck run (one alert per episode), an unexplained HELD, or a dead driver, with a banner and a critical alert. Proven by `python3 -B scripts/loop/test_run_watch.py TestRunWatch` at 41 OK.

Before the driver starts, a landing canary sends one small change through the deployed judge, and the launch refuses unless the canary prints its landing line. A refused canary keeps its gate log, and the canary runs under the scratch folder, never the system temp folder. Proven by `python3 -B scripts/loop/test_landing_canary.py TestLandingCanary` at 63 OK.

The loop report names suites that went red without any code change. A proof reader judges one named run from its own log, so an empty scope, or two runs in one log, never reads as a pass. Proven by `python3 -B scripts/loop/test_loop_works_fully.py TestLoopWorksFully` at 29 OK.

Records that expire on a date, such as the close pack and the restore drill, now make a launch refuse early and name the stale record. A held landing names the clock cause first. Proven by `python3 -B scripts/loop/test_clock_rows.py TestClockRows` at 25 OK.

The whole gate checks the committed kernel list against the code, in the private hub only. Inside the judge it compares the bytes the judge holds. Proven by `python3 -B scripts/test_kernel_closure_row.py TestKernelClosureRow` at 15 OK.

The cut rehearsal keeps its commits and records the exact tip it proved. A real cut must resume from that tip, and a cold cut needs the owner to say so. Proven by `python3 -B scripts/test_cut_keeps_rehearsal.py` at 92 OK.

The release note's mutation pool reads its disk floor early and keeps its copies under the scratch folder. A resumed cut never reads that floor. Proven by `python3 -B scripts/test_cut_preflight.py` at 118 OK.

A run's receipt now names the unit it landed, its branch and its revision. A run pushes only when it is DONE with an accept recorded on the release screen, so a rejected review pushes nothing. Proven by `python3 -B scripts/test_receipt_door.py` at 252 OK.

The private terms scan now reads escaped and split terms, and the loop's screen holds no term of its own. Proven by `python3 -B scripts/test_private_terms_escapes.py`, which ends OK.

No test spells the scratch folder's path any more, and the guard reads a fixed list, never file times. Proven by `python3 -B scripts/test_runs_root_one_rule.py` at 27 OK.

Several issues were closed at their source in this release: gate ledger rows, an approval line that could leak into a refusal message, phase timings, a hook that wrote into a shared checkout during the cut, a holder that answered any same-user peer, enrollment that trusted a terminal check, and a seed test on the export tree. The release body itself is now generated from the plan, never invented.

Every delivery report ends with one receipt sentence per unit, the acceptance screen line and, where a risk class was named, the release screen line, and the scoping sentence `exit 0 means no check failed. It does not mean everything is proven: only the checks named above ran, and a check nobody wrote cannot fail.` Proven by `python3 scripts/test_receipt_door.py` at 252 OK.

Each wait during a run prints one governor line when it starts and one when it ends, never once per poll. Proven by `python3 scripts/test_brother_run.py` at 286 OK.

The recall hook prints `Recalled N lesson(s) from the Vault for <file>` before an edit of a file the Vault knows. It prints nothing on a genuine no-match, and writes nothing before consent. Proven by `python3 products/brothermode/tools/test_vault_recall_hook.py` at 83 OK.

Vault promotion enforces separation of duties. `SEPARATION_OF_DUTIES_ENFORCED` is `True`, and an author cannot approve the same candidate: flipping the flag turns `test_the_default_policy_is_on_the_same_actor_is_refused` and `test_the_same_actor_with_no_enforce_argument_is_refused_by_default` red. Proven by `python3 products/brothermode/tools/test_bm_vault_lifecycle.py` at 42 OK.

The promote command and the approval pane apply the same rule, proven by `python3 products/brothermode/tools/test_bm_vault_promotions.py` at 27 OK and `python3 products/brothermode/tools/test_bm_vault_pane.py` at 12 OK.

The 15 legacy command shims remain in this cut, per decision D2.
