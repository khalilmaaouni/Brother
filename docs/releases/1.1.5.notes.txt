Brother 1.1.5 is the Brother.loop release. A check that is red on both the unchanged and the built copy is named as an environment defect and the build is held, never charged or parked for it: `python3 -B scripts/loop/test_land_apply_baseline.py` and `python3 -B scripts/loop/test_land_batch_env_hold.py`. A landing that changes the loop's own tools runs the deploy's freeze closure and tool parity before it commits, and is held for the maintainer's whole gate, so the loop never certifies a change to its own governance; a push that changes a loop file needs a whole-gate PASS record for exactly that tree: `python3 -B scripts/loop/test_land_batch_closure.py`, `python3 -B scripts/loop/test_land_batch_whole_gate.py`, `python3 -B scripts/test_whole_gate_record.py` and `python3 -B scripts/test_pre_push_whole_gate.py`. Stuck units are diagnosed from a stamp verified frozen copy, a newer diagnosis note counts for the next attempt, and a pass that is only waiting on a cooldown waits instead of ending the run: `python3 -B scripts/loop/test_diag_frozen_root.py`, `python3 -B scripts/loop/test_runner_pool_note_attempt.py` and `python3 -B scripts/loop/test_unproductive_cooldown.py`. Refusal text reaches the next worker only as fenced, untrusted data: `python3 -B scripts/loop/test_brief_untrusted_notes.py`. The plan lint and the grader catch what would waste a paid attempt: `python3 -B scripts/loop/test_plan_lint_rules_115.py`, `python3 -B scripts/loop/test_plan_lint_budget.py` and `python3 -B scripts/loop/test_grade_build_env_115.py`. One redeploy command checks every deploy and launch refusal before anything is stopped, and the launcher names its remedy: `python3 -B scripts/loop/test_redeploy_check.py` and `python3 -B scripts/loop/test_start_run_remedy.py`. Each run writes a summary with one state word and one next action, and every landing line shows OpenRouter cash and the Claude plan share: `python3 -B scripts/loop/test_run_summary.py` and `python3 -B scripts/loop/test_usd_plan_share.py`. Four golden journeys run at their entry points: `python3 -B scripts/loop/test_loop_golden_journeys.py`. The cut driver shows its approval question the moment it is asked: `python3 -B scripts/test_cut_driver_relay.py`.

Not verified in this release: a 24 hour qualifying run, a run at three units in flight, and a loop run on this release's own plan, which could not start because the Claude sign in had expired, so the night's loop reading is NO-DATA. Known limits, recorded with the review that found them: the grader's scan misses a file written and then deleted, or an existing ignored file rewritten; a detached grandchild of a suite can outlive its run and hold a landing at NO-DATA; and a batch that edits only a shell script under scripts/ is not counted as a deploy change.
