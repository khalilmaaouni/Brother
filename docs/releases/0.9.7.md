## What changed for developers

The public entry point tells the truth about itself: brother_run's architecture header now describes the real execution contract (a bounded 25-round drain with integration write-back, bounded repair and guaranteed termination) instead of the obsolete single-pass description an agent maintainer could have "repaired" working code toward.

Invalid input is refused by name: an outcome that cannot be encoded no longer tracebacks; the decomposer seam catches it, refuses with a named reason, exits non-zero, and leaves no half-written work record behind.

Fable authority ships bounded: every autonomous decision classifies GREEN (proceed), AMBER (proceed and record a PROVISIONAL-FABLE entry carrying the exact sentence that overrules it), or RED (credentials, spend, publishing, deletion, law changes: refused and queued for a person, and no argument buys past it). Driven backwards in 30 tests.

The merge queue plans conflict-aware integration: disjoint write sets batch into one speculative merge, overlapping sets serialize, and a submission whose check cannot run is HELD, never merged and never rejected. It emits plans and commands only; authoritative integration stays serial.

Lineage is answered: every noun in the negative-space audit now names which process originates it and which write produces it (65 cells closed with grounded call-site references, zero exemptions).

## Reliability and honesty

The enforcement act: laws_audit.py reads the estate's own law books and checks every law claiming enforcement actually names a file that exists; recall_coverage.py measures which recorded lessons fire at the point of need versus recur unguarded. Both registered in the battery.

The scheduler stops offering superseded work, record drift resolves evidence commits across the whole estate including linked worktrees and the private hub, and SYSTEM.md plus the runtime bundle mirror are regenerated and drift-checked in the same battery that gates this release.
