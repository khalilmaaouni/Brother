# Brother 0.9.9

## Source revision

Cut from hub commit `0b416b15020e28380b663c301ed76093381358d7`. Reproduce the export byte for byte with:

    python3 scripts/reproduce_export.py --source-rev 0b416b15020e28380b663c301ed76093381358d7 --tag v0.9.9 --public <local checkout of this repository>

This release supersedes 0.9.8 within hours, and the reason is recorded rather than
hidden: 0.9.8 was the cutover release that moved every product into the one
repository, and its assurance half shipped stale. The products/brothersbe subtree
had been imported weeks earlier and never re-synced, so an installed user updating
across the cutover was moved from 3.7.1 to 3.5.6, a downgrade. The cutover's own
driven update crossing caught it on the first try, which is exactly what that
check exists for.

0.9.9 ships the re-synced BrotherSBE at 3.7.1, the same one-repo layout as 0.9.8,
and nothing else new. An installed user updating from any earlier state lands on
current versions of everything.

The source revision line below is stamped by the exporter at release time.
