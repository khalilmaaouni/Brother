# Recover from failure or refusal

Classify before restarting:

- bad evidence: check already passed/irrelevant/circular;
- scope violation: write escaped the declared fence;
- dependency issue: unit cannot become ready;
- dirty baseline: target repo contains run/plan/unrelated changes;
- host capability: worker, hook trust, permissions, or model invocation unavailable;
- interrupted lane: good partial work exists in an isolated worktree;
- contract refusal: draft/open question/promised check not covered.

Preserve good partial work using current resume/continue/lane mechanisms. Do not delete state just because the high-level run stopped.

Never widen a fence, weaken a check, or remove a success criterion solely to get green.

## Verify the result

The resumed/new receipt addresses the original refusal rather than hiding it.
