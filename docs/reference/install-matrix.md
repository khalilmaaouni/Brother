# Install matrix

Choose your host and follow its installation guide.

| Host and install guide | Brother surface | Hook/trust note |
| --- | --- | --- |
| [Claude Code](../how-to/install-claude-code.md) | Plugin commands and skills | Product installers can limit hooks to chosen repositories; check the scope after installation. |
| [Codex](../how-to/install-codex.md) | Installed Brother skill | Hook setup and trust are separate steps; verify that Codex reports them active. |
| [Cursor](../how-to/install-cursor.md) | Local plugin with commands and skills | Installation alone does not prove that a hook can refuse a write. Follow the guide's verification steps. |

Install success does not prove hook scope, target-repo opt-in, worker availability, or that a real run can produce a receipt. Smoke-test the installed path.
