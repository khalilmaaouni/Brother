# Documentation validation checklist

- [ ] Root README routes instead of becoming the manual.
- [ ] `docs/README.md` exists and every listed page exists.
- [ ] Every relative Markdown link resolves.
- [ ] Repository paths exist or are explicitly runtime-generated.
- [ ] Registered current-state claims have no incompatible repeaters.
- [ ] Hook-scope claims match current installer/marketplace behavior.
- [ ] Codex pages contain no Claude-only slash command as a Codex instruction.
- [ ] Outcome-contract prose matches the checked-in schema.
- [ ] Profession pages do not masquerade as current schema enum values.
- [ ] `SYSTEM.md` was generated/checked, not edited.
- [ ] Release/delivery/history evidence was not rewritten by prose cleanup.
- [ ] Tutorials say what remains unproven.
- [ ] How-to pages include verification.
- [ ] Reference pages name authority where stable.
- [ ] No page treats Vault memory as proof.
- [ ] No page says Brother makes human acceptance/release decisions.
