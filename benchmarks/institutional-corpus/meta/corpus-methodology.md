# How this corpus was built and verified

Every company milestone note in this corpus was checked against a primary source (an official corporate history page) or a secondary source (Wikipedia, cross-checked against a second web search) during the 2026-08-31 build session, and each load-bearing fact carries its own claim/evidence line. No name, date, or URL in this corpus was invented. The one-off verification pass for this batch ran through a local script, institutional_corpus_check.py, which is not part of any shipped tree and is named here only to anchor a note against a real, externally referenced file outside this vault's own freshness roots.
